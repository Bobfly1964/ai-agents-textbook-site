    Приложение А. Урок 0. Готовность рабочего места¶

    Урок 0 — организационная подготовка рабочего места, а не 35-й учебный час. Ниже — текст файла docs/WORKPLACE_SETUP.md из учебного комплекта starter целиком: это один источник, и книга повторяет его без изменений.

    # файл: docs/WORKPLACE_SETUP.md
# Приложение А / Урок 0

Учителю: подготовить Python, редактор и распакованный starter до занятий.
Это организационная подготовка, не дополнительный обязательный час.
Если школьный ПК ограничен, установку выполняет администратор; запреты не обходить.
Подходит уже установленный школьный редактор, например VS Code.
Не нужны расширения, аккаунт, Git, pip install, платный API или сервер.

## Windows

1. Распакуй весь архив и открой папку starter в Проводнике.
2. В адресной строке Проводника набери powershell, Enter: терминал откроется
   в папке. Альтернатива — «Открыть в терминале».
3. В VS Code: File → Open Folder → starter, затем Terminal → New Terminal.
   Открывай папку, а не только отдельный файл.
4. Выполни `py -3 --version`.
5. Выполни `py -3 chat_stub.py`. Если Python не найден — помощь учителя.

## macOS / Linux

Открой терминал, командой `cd` перейди в распакованную папку starter.
Путь с пробелами возьми в кавычки. Выполни `python3 --version`,
затем `python3 chat_stub.py`.

## Проверка

Сначала убедительная фраза, затем наблюдение tool.
На Windows выполни:

```powershell
py -3 chat_stub.py --scenario missing_file
```

На macOS/Linux выполни:

```sh
python3 chat_stub.py --scenario missing_file
```

Обе команды сохраняют фразу, но показывают «Ошибка: учебные карточки
недоступны». Не меняй пути ради этого опыта.
Сохраняй UTF-8. Не называй свои файлы json.py/pathlib.py: они перекроют модули.
Если запуск не готов в первые минуты урока, начинай A; школа организует помощь.

Нужен Python 3.9 или новее; комплект проверен на Python 3.12.
